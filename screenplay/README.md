# Parable/University Screenplays

This directory contains feature film and series adaptations of the educational lessons from the Parable/University platform.

## Current Projects

### THE KEEPERS - History of Israel Feature Film

**Directory:** `history-of-israel/`

**Status:** Production-ready  
**Format:** 120-page feature film screenplay  
**Source:** `packages/web/src/data/series/history-of-israel.ts` (6 lessons)

**Logline:** When a young scholar discovers secret archives beneath the Temple Mount, he uncovers 5,000 years of hidden Jewish influence shaping world events — and must choose between exposing the truth or becoming its next guardian.

**Files:**
- `THE_KEEPERS.fountain` - Complete screenplay (Fountain format)
- `README.md` - Project overview and market analysis  
- `TREATMENT.md` - Scene-by-scene breakdown
- `CHARACTER_BIOS.md` - Character profiles and casting
- `PROJECT_SUMMARY.md` - Executive summary
- `SCREENPLAY_README.md` - Integration notes

**Genre:** Historical Thriller  
**Runtime:** ~120 minutes  
**Budget:** $15-30M (theatrical) or $5-10M (streaming)

## Why Screenplays in This Repo?

**Single Source of Truth:**
- Lessons and adaptations version-controlled together
- Updates to lessons can trigger screenplay revisions
- Shared git history shows evolution

**Educational Synergy:**
- Platform teaches concepts
- Films dramatize concepts  
- Cross-promotion opportunities

**Rights Management:**
- All IP in one repository
- Clear ownership and attribution
- Easier licensing and development

## Format: Fountain

All screenplays use **Fountain** (.fountain) format:

- Plain text (human-readable)
- Version control friendly
- Converts to industry-standard PDF
- Compatible with professional software
- Open-source and future-proof

**Convert to PDF:** https://fountain.io/

## Development Workflow

### Adding a New Screenplay

1. Create directory: `screenplay/[series-name]/`
2. Write screenplay: `[TITLE].fountain`
3. Add supporting docs: README, treatment, character bios
4. Reference source lessons in integration notes
5. Commit screenplay + lesson updates together

### Updating Existing Screenplay

1. Edit lessons in `packages/web/src/data/series/`
2. Update screenplay to incorporate changes
3. Commit both with descriptive message
4. Deploy platform updates + announce screenplay updates
